SETUP & DOCUMENTATION

Installation & Requirements

01

Install Server

Download CAMS-Server-Setup.exe on the teacher PC and double-click. The installer opens firewall, creates shortcuts, and auto-launches the dashboard.

02

Install Clients

Download CAMS-Client-Setup.exe on each student PC. The installer prompts for the server address and auto-launches the client.

03

Log In & Manage

Log in using default credentials (Admin/Teacher/Student). Monitor screens, manage classes, and allocate resources.

HELP & TROUBLESHOOTING

Frequently Asked Questions

Q: What if the client cannot find the server automatically?

Ensure both machines are on the same LAN subnet and Windows Firewall allows UDP port 5001. The installer prompts for manual server address if auto-discovery fails.

Q: How do I change the default database?

In appsettings.json, set "DatabaseProvider": "Sqlite" (default CAMS.db), "SqlServer", or "MySql" along with your connection string.

Q: Windows SmartScreen blocked the application?

Because the binaries are built locally without an EV code-signing certificate, click "More info" → "Run anyway".
