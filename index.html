INTRODUCTION

What’s CAMS?

CAMS (Computer Account Management System) is a self‑hosted solution for managing computers in a classroom or lab environment. It provides UDP auto‑discovery, live screen monitoring, role‑based security, and a simple installer for both server and client.

SETUP GUIDE

How to Install CAMS

Server Installer

Download CAMS‑Server‑Setup.exe and run it on the teacher PC.

Client Installer

Download CAMS‑Client‑Setup.exe on each student PC.

First Login

Default credentials admin / admin123. Change after first login.

FEATURES

How to Operate CAMS

UDP Auto‑Discovery

Clients auto‑locate the server on the LAN without manual IP entry.

Live Screen Monitoring

View student screens in real‑time via WebSocket.

Role‑Based Security

Separate admin, teacher, and student permissions with CSRF protection.

Multi‑Database Support

SQLite out of the box, or switch to SQL Server / MySQL via configuration.
