INTRODUCTION

What is CAMS?

CAMS (Computer Account Management System) is a self‑hosted solution for managing computers in a classroom or lab environment. It provides UDP auto‑discovery, live screen monitoring, role‑based security, and a simple installer for both server and client.

SETUP GUIDE

How to Install CAMS

01

Server Installer

Download CAMS‑Server‑Setup.exe and run it on the teacher PC. The installer creates shortcuts, opens the firewall, and launches the dashboard automatically.

02

Client Installer

Download CAMS‑Client‑Setup.exe on each student PC. Provide the server address if auto‑discovery fails.

03

First Login

Default credentials: admin / admin123. Change passwords immediately in the admin panel.

OPERATIONS

How to Operate CAMS

UDP Auto‑Discovery

Clients automatically locate the server on the LAN without any manual IP entry.

Live Screen Monitoring

View student screens in real‑time via a SignalR WebSocket connection.

Role‑Based Security

Separate admin, teacher, and student permissions with CSRF protection and rate‑limited logins.

Multi‑Database Support

SQLite out of the box, or switch to SQL Server / MySQL via `appsettings.json`.

Auto‑Launch Dashboard

Server.exe automatically opens the web dashboard after installation.
