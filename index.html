COMPUTER ACCOUNT MANAGEMENT SYSTEM — V2.5

Control every machine in the classroom.

CAMS is a lightweight LAN classroom management system. Auto-discovery, real-time monitoring, and role-based control — running entirely on your own network. No cloud, no accounts, no install.

FEATURES

Built for the LAN, not the cloud.

Auto-Discovery

Clients find the server automatically over the LAN with zero configuration. No IP hunting, no setup wizards — plug in and connect.

Portable, Zero Install

Both server and client run straight from a single executable. Carry them on a USB stick — nothing is installed on student machines.

Real-Time Monitoring

Watch every connected machine live. Admins, teachers and students each get role-scoped control over the classroom network.

QUICK START

Up and running in 3 steps.

01

Download the Server

Run CAMS-Server on the teacher's machine. It auto-starts and broadcasts its address on the LAN.

02

Install Clients

Launch CAMS-Client on each student PC. The server is found automatically — or type its IP if needed.

03

Log In & Control

Sign in as Admin, Teacher or Student. Your role decides what you can see and manage on the network.
